# Oracle Workshop Environment

## Overview

This folder documents the Oracle environment used to complete the hands-on workshop.

## Environment Used

The lab environment included:

* Oracle Cloud Infrastructure (OCI)
* Oracle Autonomous Database
* Oracle Database Actions
* SQL Worksheet
* Oracle Graph capabilities

## Database Access

The Autonomous Database was accessed through Oracle Database Actions.

SQL Worksheet was used to:

* Connect to the database
* Execute SQL statements
* Create and query database objects
* Validate sample data
* Test queries required during the workshop

## Graph Environment

Oracle Graph functionality was explored as part of the hands-on activities.

The environment was used to:

* Work with graph-related database objects
* Execute graph queries
* Create graph visualizations
* Validate the results returned by the graph queries

## Environment Validation

Before performing the workshop activities, the database connection and required services were verified to ensure that the environment was available for the hands-on exercises.

## Notes

This was a workshop/lab environment used for learning and demonstration purposes. No production credentials, passwords, connection strings, or other sensitive information are included in this repository.
