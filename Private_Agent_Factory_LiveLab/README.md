## Data Analysis Agent

I created a **Movie Analysis Agent** using the Movies Dataset available in the workshop environment.

The agent was configured to analyze structured data and answer questions using natural language.

One of the queries tested was:

> Show me the top 10 movie genres by number of titles and compare their average release year.

The agent analyzed the underlying data and returned the requested results.

Supporting screenshots are available in the `screenshots` directory.

## Knowledge Agent

I configured a file-based data source and uploaded Oracle Private Agent Factory documentation.

A Knowledge Agent was then used to answer questions based on the uploaded documentation.

Example question:

> What are the different ways to build an Agent within the Oracle Private Agent Factory?

The agent returned a grounded response and provided the uploaded document as the supporting source.

## Agent Builder

I also worked with the Private Agent Factory **Agent Builder** to understand how individual components can be connected to create custom agent workflows.

The workflows included components such as:

* Chat Input
* SQL Query
* Prompt
* Agent
* Chat Output

A database-driven **Netflix Analysis Agent** workflow was built to combine user questions with SQL query results and pass the grounded prompt to the configured AI model.

This provided practical experience with how database data, prompts and AI agents can be combined into an end-to-end agentic workflow.
