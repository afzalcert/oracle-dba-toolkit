# Oracle Workshop – Hands-on Lab

## Overview

This folder documents my hands-on Oracle workshop activities and supporting evidence as part of my continuous learning and practical experience with Oracle technologies.

The objective of this workshop was to gain practical experience by working directly with Oracle Cloud and database services and completing the required hands-on lab activities.

## Workshop Activities

During the workshop, I performed the following activities:

* Created and configured the required Oracle environment.
* Accessed Oracle Autonomous Database.
* Used Oracle Database Actions and SQL Worksheet.
* Created database objects required for the lab.
* Loaded and queried sample data.
* Executed SQL queries to validate the data.
* Worked with Oracle Graph capabilities.
* Created graph visualizations to explore relationships within the data.
* Executed and validated graph queries.
* Troubleshot issues encountered during the hands-on activities.
* Reviewed and validated the final results.

## Environment

The workshop environment included:

* Oracle Cloud Infrastructure (OCI)
* Oracle Autonomous Database
* Oracle Database Actions
* SQL Worksheet
* Oracle Graph capabilities
