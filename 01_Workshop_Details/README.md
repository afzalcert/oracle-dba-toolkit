# Oracle Workshop – Hands-on Lab

## Overview

This folder contains details and supporting evidence from an Oracle hands-on workshop completed as part of my continuous learning and practical experience with Oracle technologies.

The objective of the workshop was to gain hands-on experience by working directly with Oracle services and completing the required lab activities.

## Workshop Activities

During the workshop, I worked on the following activities:

* Created and configured the required Oracle environment.
* Connected to the Oracle database using SQL tools.
* Created database objects required for the lab.
* Loaded and queried sample data.
* Executed SQL queries to validate the data.
* Worked with Oracle Autonomous Database features.
* Created graphs/visualizations using the available database tools.
* Verified the configuration and reviewed the results.

## Environment

The workshop was performed using:

* Oracle Cloud Infrastructure (OCI)
* Oracle Autonomous Database
* Oracle Database 23ai/26ai related features
* Oracle Database Actions / SQL Worksheet
* Graph capabilities available within the Oracle environment

## Repository Evidence

Supporting evidence from the workshop is maintained in this repository, including screenshots and other relevant files where applicable.

The repository also contains Oracle DBA scripts covering areas such as:

* ASM
* RAC
* Data Guard
* RMAN
* Performance Monitoring
* Database Security

## Purpose

The purpose of documenting this workshop is to demonstrate practical usage of Oracle technologies and maintain a record of hands-on learning and experimentation.

This work is part of my ongoing Oracle technology learning and Oracle ACE Apprentice journey.
