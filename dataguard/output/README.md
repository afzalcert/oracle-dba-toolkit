# Data Guard Output

This directory contains sample output generated while running the Data Guard monitoring scripts and DGMGRL commands available in the parent directory.

Output files are kept separately from the SQL scripts for easy reference.

Typical outputs include:

* Data Guard status
* Transport and apply lag
* Archive gap check
* Data Guard Broker status and validation

All environment-specific information such as database names, hostnames, service names and IP addresses should be masked before uploading the output files to this repository.
